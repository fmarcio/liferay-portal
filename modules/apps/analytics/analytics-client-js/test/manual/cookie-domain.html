Anonymous user id shared across subdomains

Serve this page from two hostnames that share one registrable domain, so the browser can be seen sharing the ac_client_user_id cookie between them. Add 127.0.0.1 site.test learn.site.test to /etc/hosts, then open http://site.test:8081/test/manual/cookie-domain.html and http://learn.site.test:8081/.... The client marks the cookie Secure, so those origins must count as secure: 
google-chrome --user-data-dir=/tmp/ac-sdk-profile \
--unsafely-treat-insecure-origin-as-secure=http://site.test:8081,http://learn.site.test:8081
