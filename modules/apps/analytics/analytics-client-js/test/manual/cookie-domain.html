Anonymous user id shared across subdomains

Reach this page through two hostnames that share one registrable domain, so the browser can be seen sharing the ac_client_user_id cookie between them.

Two servers are needed. yarn start serves the bundle alone on port 8081, so this page needs a static server of its own, from the module root: 

yarn start                      # bundle at localhost:8081
python3 -m http.server 8000     # this page, from the module root

lvh.me and every subdomain of it resolve to the loopback address through public DNS, so no /etc/hosts entry is needed. Open http://lvh.me:8000/test/manual/cookie-domain.html and the same path on http://learn.lvh.me:8000. Should that domain ever stop resolving, any two names in /etc/hosts that share a registrable domain work the same way.

The client marks the cookie Secure, which the browser accepts only from an origin it considers secure, so those two origins have to be declared as such: 

google-chrome --user-data-dir=/tmp/ac-sdk-profile \
--unsafely-treat-insecure-origin-as-secure=http://lvh.me:8000,http://learn.lvh.me:8000
